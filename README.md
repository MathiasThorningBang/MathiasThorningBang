# Hi, I'm Mathias

I come from UX and web development and now spend most of my time on AI. I run [Bang & Co](https://www.bangco.dk/) with my dad, where we build websites, internal tools and the occasional iOS or macOS app.

## Things I've made in the open

**[markdown-editor](https://github.com/MathiasThorningBang/markdown-editor)**
A small macOS WYSIWYG markdown editor built with SwiftUI and Milkdown. It is currently being rebuilt into something new, so keep an eye out.

**[web-assets](https://github.com/MathiasThorningBang/web-assets)**
I got tired of clients sending 40 MB images and expecting them to go straight onto their website. This Claude Code plugin converts local images and videos into web-ready WebP, AVIF, MP4 and WebM with cwebp and ffmpeg.

**[wireframe-skill](https://github.com/MathiasThorningBang/wireframe-skill)**
A Claude Code skill that turns any live website into a grayscale HTML wireframe. I use it when I iterate on layouts directly in code. An upgrade is on the way, and it ends up in the same new thing as the markdown editor.
